# Logo concepts (round 1)

Four concept marks for Main Method LLC. Each is a 100x100 SVG in ink (`#111513`) with a green accent (`#1d6a47`).

| File | Concept | Idea |
| --- | --- | --- |
| `a-origin.svg` | Origin | An M drawn as one line that starts from a dot (the entry point). Recommended. |
| `b-call.svg` | m() | Lowercase m plus an empty call. Most literal. |
| `c-body.svg` | Body | Braces around a single point. Common dev trope. |
| `d-notch.svg` | Notch | Solid block M with a dot in the notch. Best at tiny sizes. |

These are concept drawings, not final assets. The chosen mark still needs optical tuning, a simplified 16px favicon, and a trademark search.
